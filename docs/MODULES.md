# Mappi modules

## Maps

A library and spatial editor for tasks, decisions, approvals, and interconnections. Nodes and connections can be rearranged, while the contextual inspector asks only for the configuration required by the selected step.

In this public demo, an interconnection records the related map as task context; it does not silently start a second run.

## Tasks

A board generated by map execution. Each card retains its source map, step, checklist, and deadline. The next task appears only after the current one meets its requirements and passes review.

## Calendar

A time-based view of the same tasks. Moving between modules never creates a duplicate record or asks the user to configure the same work again.

## Apps

A contextual catalog that brings capabilities closer to maps. Every connection in this public case is a local simulation: no external account is connected and no real integration is claimed.
